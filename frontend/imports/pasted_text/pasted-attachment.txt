# SERVER-SIDE PRICE SECURITY

Never trust product prices calculated or submitted by the browser.

When a customer places an order:

1. Send product IDs, add-on IDs and quantities to the Node.js server.
2. Backend retrieves current product prices from MongoDB.
3. Backend retrieves current add-on prices from MongoDB.
4. Backend validates that each product is available.
5. Backend recalculates the complete order total.
6. Backend creates the final order.
7. Backend stores product/add-on price snapshots in the order.

Never allow customers to manipulate prices through frontend state.

# REAL DATABASE ORDER SYSTEM

The primary checkout action should be:

**PLACE ORDER**

Do NOT make WhatsApp the only order-storage mechanism.

When Place Order is clicked:

1. Frontend sends order request to Node.js backend.
2. Backend validates customer fields.
3. Backend validates every product.
4. Backend confirms availability.
5. Backend fetches current product prices from MongoDB.
6. Backend validates selected add-ons.
7. Backend fetches current add-on prices.
8. Backend recalculates final order total.
9. Backend generates unique order number.
10. Backend stores complete order in MongoDB.
11. Initial status becomes **Pending**.
12. Return confirmed order number to frontend.
13. Clear cart after successful response.
14. Redirect customer to Order Confirmation page.
